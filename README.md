# Machine Learning Assignments

A collection of my Machine Learning coursework and hands-on implementations, covering fundamental learning algorithms, supervised and unsupervised learning, model evaluation, regularization, dimensionality reduction, and representation learning.

The repository documents my progression from implementing core machine learning methods from scratch to applying established models to real-world datasets and investigating how feature representations affect model performance.

## Assignments

| Assignment       | Focus                                           | Key Topics                                                                                                                                                                        |
| ---------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Assignment 1** | Machine Learning Foundations                    | Data generation, linear regression, gradient descent, L1/L2 regularization, ridge regression, model stability, bias–variance, loss functions                                      |
| **Assignment 2** | Supervised Learning & Regression                | Credit card default prediction, bike-sharing demand, wine quality prediction, preprocessing, PCA, model comparison, hyperparameter tuning, feature importance, distribution shift |
| **Assignment 3** | Ensembles, Clustering & Representation Learning | Random Forest, AdaBoost, K-Means, hierarchical clustering, DBSCAN, PCA, t-SNE, UMAP, CNN features, nearest-neighbor analysis                                                      |
